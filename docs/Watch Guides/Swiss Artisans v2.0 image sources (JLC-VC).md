# Image sources — JLC × Vacheron Constantin guide (researched 2026-08-13)

Sourcing rules applied: dial-forward, high-resolution, reputable photography (auction houses,
specialist dealers, manufacturer press). Direct image URLs were extracted where the page allowed
it; some sites lazy-load images and only the page URL could be captured — noted per entry.
No files were downloaded.

## 13. VC Historiques Triple Calendrier 1942, ref 3110V steel (blue accents)

- **Page URL:** https://monochrome-watches.com/vacheron-constantin-historiques-triple-calendrier-1942-review-price/
- **Direct images:**
  - https://monochrome-watches.com/app/uploads/2017/10/Vacheron-Constantin-Historiques-Triple-Calendrier-1942-Review-9.jpg
  - https://monochrome-watches.com/app/uploads/2017/10/Vacheron-Constantin-Historiques-Triple-Calendrier-1942-Review-10.jpg
- **Credit:** Monochrome Watches (review, Oct 2017)
- **What it shows:** Steel 3110V, 40mm, triple calendar, **no moonphase** (confirmed — correct model). The review photographs BOTH accent variants (blue and burgundy) side by side.
- **B425 vs B426 warning:** sources disagree on which suffix is blue — most retail listings pair **B425 with blue accents** (e.g., The 1916 Company review titled "3110V/000A-B425"), but at least one summary reverses it. Pick the blue-accent photo visually and verify the suffix against the seller's own spec sheet before printing it in the guide.
- **Caveat:** Monochrome is not on the source list (model now discontinued, off vacheron-constantin.com; no on-list dealer example found photographed well) — its review photography is excellent and dial-forward.
